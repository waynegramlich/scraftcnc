# Summary of `I.mpgtis` Main Part Goes Translucent in show_demo

Not a regression: SolidCraft makes whatever is under the mouse pointer translucent (the user found it; with the pointer out of the window the plate stays solid).  The plate is modeled solid, and `show_demo.py` models no stock.  No SolidCraft command turns the hover effect off, so `README.md` (step 5 of "Trying It") tells users to keep the pointer out of the window.
