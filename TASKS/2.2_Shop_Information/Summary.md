# Summary of `T.si` Shop Information

Shops are Nested TOML files read and checked by `shops.py`, which writes `Shops.md` from its schema (a test keeps them in step).  Every number has
a unit; `"@FILE"` splices a file; every problem is reported at once as `FILE:LINE: KEY: message`; open lists take a value ending in `!`.  A tool
is in one machine at a time.  `shars_catalog.md` (not in version control) maps the catalog.
