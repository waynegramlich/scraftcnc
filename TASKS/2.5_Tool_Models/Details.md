# 2.5 Tool Models

3D models of the tools (draft by Claude, 2026-10-27; the user's to
revise; `T.cuwp~2` #25).

* Each tool's profile (lines and arcs, tip up the shank) built from
  its description in the tools files and revolved about its axis
  (`solid.revolve`), for a tool gallery in SolidCraft, for placing
  edge finishing bits ("where must the profile sit to touch this
  edge"), and later for gouge checks and simulation.
